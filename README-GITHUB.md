# FireMap Louiseville — version GitHub

Cette version affiche les bornes sur fond noir avec :

- couleur de la borne calculée selon le débit en gal/min;
- nombre de gal/min directement sous l’icône;
- contour vert, jaune, rouge ou gris selon la disponibilité;
- formulaire en gallons par minute;
- compatibilité avec les anciens statuts Firebase.

## Mise en ligne

Décompressez le ZIP, téléversez tous les fichiers à la racine du dépôt GitHub, puis cliquez sur **Commit changes**.


## Recherche d’adresse simplifiée (V6)

La recherche accepte maintenant les adresses sans type de voie et les abréviations courantes :

- `192 Notre-Dame` trouve `192 Rue Notre-Dame`
- `507 St-Laurent` trouve `507 Boulevard Saint-Laurent`
- `80 St-Paul` trouve `80 Rue Saint-Paul`
- `Ste-Élisabeth` trouve `Sainte-Élisabeth`
- `boul`, `av`, `ch` et `rte` sont aussi reconnus


## Ajout rapide sur la carte
Double-cliquez sur ordinateur ou double-touchez sur téléphone à l’endroit voulu. Choisissez ensuite **borne-fontaine** ou **bâtiment à risque**. Les coordonnées GPS et, lorsqu’une adresse est proche, l’adresse sont préremplies.
