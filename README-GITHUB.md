# FireMap Louiseville — version GitHub

Cette version affiche les bornes sur fond noir avec :

- couleur de la borne calculée selon le débit en gal/min;
- nombre de gal/min directement sous l’icône;
- contour vert, jaune, rouge ou gris selon la disponibilité;
- formulaire en gallons par minute;
- compatibilité avec les anciens statuts Firebase.

## Mise en ligne

Décompressez le ZIP, téléversez tous les fichiers à la racine du dépôt GitHub, puis cliquez sur **Commit changes**.
