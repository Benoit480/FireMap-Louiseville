# FireMap Louiseville V10 — Appui long 1 seconde

Cette version remplace le double-clic/double-tap par un mode édition fiable sur iPhone, Android et ordinateur.

1. Ouvrez la carte.
2. Activez **✏️ Édition : OUI**.
3. Maintenez votre doigt ou la souris pendant **1 seconde** sur l'emplacement choisi.
4. Choisissez **borne-fontaine** ou **bâtiment à risque**.

Le mode édition est désactivé par défaut pour éviter les ajouts accidentels. Les bornes, préplans, adresses et données Firebase existantes sont conservés.
