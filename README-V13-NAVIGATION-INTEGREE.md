# FireMap V13 — Navigation GPS intégrée simple

## Nouveautés
- Trajet routier dessiné directement dans FireMap.
- Position GPS suivie en temps réel.
- Distance et durée estimées.
- Prochaine manœuvre et liste des indications.
- Recalcul automatique lorsque le véhicule s’éloigne du point de départ du trajet.
- Recalcul manuel.
- Bouton de secours Apple Plans / Google Maps.

## Utilisation
1. Ouvrir l’Assistant d’intervention.
2. Choisir l’adresse.
3. Appuyer sur « Navigation intégrée ».
4. Autoriser la localisation.

Le calcul routier nécessite une connexion Internet. Le GPS peut continuer à afficher la position, mais un nouveau trajet ne peut pas être calculé hors ligne. Cette fonction est une aide cartographique et ne remplace pas les procédures du service ni le jugement du conducteur.
