# FireMap V15 — Import SMS de répartition

## Nouvelle fonction

Dans **Assistant d’intervention**, ouvrir **📩 Importer le SMS de répartition** :

1. Copier le SMS reçu de la répartition.
2. Coller le message dans FireMap.
3. Appuyer sur **🚨 Créer l’appel actif**.

FireMap extrait automatiquement :

- la nature de l’appel;
- l’adresse de Louiseville;
- le niveau ou cas d’alarme lorsqu’il est présent.

L’application ouvre ensuite l’appel actif, le préplan, les bornes recommandées et la navigation intégrée.

## Raccourci iPhone facultatif

Un raccourci iOS peut ouvrir FireMap avec le texte du message encodé dans :

`https://benoit480.github.io/NOM-DU-DEPOT/?appel=TEXTE_ENCODE`

Le paramètre peut aussi s’appeler `sms` ou `text`.
