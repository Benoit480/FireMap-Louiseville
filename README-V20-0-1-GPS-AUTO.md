# FireMap V20.0.1 — GPS automatique

Modifications :
- Le GPS et la navigation intégrée démarrent automatiquement lorsqu’une intervention est activée.
- Le GPS s’arrête automatiquement lorsque l’intervention est terminée.
- La ligne de navigation est bleue.
- La carte est centrée automatiquement sur l’adresse de l’intervention.
- Le bouton GPS manuel reste disponible comme solution de secours.

Remplacez tous les fichiers du dépôt de développement, puis faites Ctrl+F5 sur PC ou fermez/réouvrez la PWA sur iPhone.
