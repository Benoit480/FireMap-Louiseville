# FireMap V20.1.2 — Prévention devient le préplan

Les informations enregistrées dans le mode Prévention alimentent maintenant automatiquement le préplan opérationnel du bâtiment.

- éléments vérifiés
- risques particuliers
- électricité, gaz, FDC et accès
- observations
- photos classées par catégorie
- date de visite, inspecteur et prochaine révision

Lors de l’enregistrement d’une visite, les champs principaux du bâtiment sont aussi mis à jour et synchronisés dans Firestore.
