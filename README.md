# FireMap Louiseville — Firebase

Application FireMap hébergée sur GitHub Pages avec les données des bornes synchronisées dans Firebase Cloud Firestore.

## Synchronisation

- Collection : `bornes`
- Mise à jour en temps réel entre les appareils
- Authentification anonyme automatique
- Copie locale conservée pour la continuité de service
- Photos conservées localement

## Installation

Suivre `INSTALLATION-FIREBASE.md`, puis publier le contenu de `firestore.rules` dans la console Firebase.
